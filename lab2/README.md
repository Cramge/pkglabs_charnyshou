# Лабораторная работа 2

Автор: Чернышов Матвей, 2 курс, группа 10б.

Программа считывает метаданные JPEG, GIF, TIFF, BMP, PNG и PCX вручную из бинарных структур. Расширение файла не используется для определения формата. Pillow применяется только для предпросмотра выбранного изображения.

## Запуск

```powershell
python main.py
```

## Получение данных

- JPEG: размеры, число компонентов и глубина берутся из маркера SOF; разрешение — из APP0 JFIF; тип сжатия определяется по коду SOF; наличие EOI проверяется отдельно.
- GIF: размеры берутся из логического дескриптора экрана; глубина и размер палитры — из полей глобальной и локальной таблиц; блоки обходятся до завершающего байта; сжатие — LZW.
- TIFF: порядок байтов определяется по сигнатуре II или MM; теги первого изображения и цепочка IFD разбираются вручную; поддерживаются обычный TIFF и BigTIFF; проверяются смещения полос и тайлов.
- BMP: читаются BITMAPFILEHEADER и DIB-заголовок; глубина, разрешение, палитра и код сжатия берутся из полей заголовка; проверяются объявленный размер и границы массива пикселей.
- PNG: размеры, глубина и тип цвета берутся из IHDR; разрешение — из pHYs; чанки обходятся по длинам без чтения IDAT; проверяются CRC заголовка и наличие IEND.
- PCX: размеры, разрешение, число плоскостей и глубина берутся из 128-байтового заголовка; RLE-поток проверяется последовательно без загрузки в память.

## Архитектура

- `presentation` — интерфейс, таблица, прогресс, CSV и предпросмотр.
- `core` — модели данных, многопоточный обход и отмена.
- `infrastructure` — двоичный reader и ручные парсеры форматов.

Сканирование выполняется в ограниченном пуле потоков. В памяти одновременно находятся только пути, небольшие части заголовков и результаты. Чанки PNG, сегменты JPEG, блоки GIF и TIFF-данные обходятся по смещениям. Интерфейс получает результаты пакетами и остаётся доступным во время работы.
