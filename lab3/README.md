# Лабораторная работа 3

Вариант 10: нелинейные фильтры на основе порядковых статистик, два метода глобальной пороговой обработки и адаптивная пороговая обработка.

## Реализованные методы

- медианный и максимальный фильтры;
- глобальный порог Оцу;
- итеративный глобальный порог;
- адаптивный порог Сауволы через интегральные изображения суммы и квадратов;
- обработка краев Reflect и Clamp;
- гистограммы исходного и обработанного изображений.

Все алгоритмы работают с собственным пиксельным буфером. Pillow используется для открытия, сохранения и отображения файлов. Обработка выполняется в фоновом потоке, а строки изображения распределяются между рабочими потоками.

## Запуск

```powershell
python main.py
```

Для проверки:

```powershell
python -m unittest discover -s tests -v
```

Для сборки:

```powershell
python build.py
```
